# Trip video music

Background music mixed into exported trip videos. Both tracks are CC0 (public
domain dedication), downloaded from OpenGameArt, loudness-normalized to -16 LUFS
and re-encoded as 128 kbps MP3.

| File              | Track               | Author            | Source                                              |
| ----------------- | ------------------- | ----------------- | --------------------------------------------------- |
| `chill-lofi.mp3`  | Chill lofi inspired | omfgdude          | https://opengameart.org/content/chill-lofi-inspired |
| `apple-cider.mp3` | Apple Cider         | Zane Little Music | https://opengameart.org/content/apple-cider         |
